    How to bend a rolling offset

    1. Measure rise and roll between the same points on both runs (center to center, or bottom to bottom).
    2. Find the true offset: √(rise² + roll²). A 6-8-10 (3-4-5) triangle is a quick check.
    3. Bend a normal offset for the true offset: distance between bends = true offset × multiplier. Keep both bends in one plane.
    4. Roll it into place: tilt the offset from vertical toward the roll by the angle shown (the angle whose tangent is roll ÷ rise).

    Worked example

    Rise 6", roll 8": true offset √(36 + 64) = 10". With 30° bends: 10" × 2 = 20" between bends, shrink about 2 11/16" (10" × 0.268). Tilt the offset 53.1° from vertical toward the roll.

    About the numbers: these calculators use the point model behind apprenticeship charts — each bend is treated as a sharp corner. Real benders have a radius and some springback, which shift the marks slightly. Bend and measure a test piece from scrap before you bend a run. This page uses no electrical-code data.

    Common questions

    What is a rolling offset?

    An offset that moves the conduit up (or down) and sideways at the same time. Instead of bending two separate offsets, you bend one offset sized for the diagonal and roll it to the needed angle.

    How do you calculate a rolling offset?

    Square the rise and the roll, add them and take the square root: that is the true offset. Then bend it like any offset: distance between bends = true offset × multiplier, and shrink = true offset × shrink per inch.

    What angle do I roll the offset to?

    Tilt the offset from vertical toward the roll by the angle whose tangent is roll ÷ rise. For a 6-inch rise and an 8-inch roll that is about 53° from vertical.
